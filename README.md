# n8n Workflows

Real-world n8n workflows, each in its own folder with an importable workflow JSON and setup notes.

| Workflow | What it does |
|---|---|
| [cricket-whatsapp-helpdesk](cricket-whatsapp-helpdesk/) | Answers parents' WhatsApp questions about a cricket tournament (fixtures, venues, timings, squads) from a Google Sheet, replying privately to each parent. |

`prompts/` holds the RCTFC prompts used to design these workflows.
